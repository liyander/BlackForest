# Build Guide: BlackFrost PE Strings Lab

This guide explains how to build the lab artifacts from source and prepare the files for players.

The lab is a safe, synthetic malware-analysis challenge. The generated executable is an inert PE-style artifact designed for static analysis practice in PE Studio, strings tools, and CyberChef.

## Requirements

- Windows, Linux, or macOS
- Python 3.10 or newer
- Optional analysis tools for validation:
  - PE Studio
  - Sysinternals Strings, FLOSS, or the included `scripts\extract_strings.py`
  - CyberChef

No external Python packages are required.

```text
+-- docs\
|   +-- info.md

|   +-- walkthrough.md

+-- dist\
    +-- BlackFrost_Update.exe
    +-- README_FIRST.txt
    +-- SHA256SUMS.txt
    +-- memory_strings.txt
    +-- network.log
```

`dist\` is generated by the build script. If it does not exist yet, the build script creates it.

## Build Steps

From the repository root, run:

```powershell
python .\scripts\build_lab_artifacts.py
```

Expected output:

```text
Wrote C:\path\to\repo\dist\BlackFrost_Update.exe
SHA256 <sample hash>
```

The script creates:

- `dist\BlackFrost_Update.exe` - synthetic PE-style challenge sample
- `dist\SHA256SUMS.txt` - SHA256 hash for the generated sample
- `dist\README_FIRST.txt` - short player handout
- `dist\network.log` - supporting network telemetry
- `dist\memory_strings.txt` - supporting recovered-memory strings

The telemetry files are intentionally noisy. They include benign enterprise activity, decoy updater indicators, false flag candidates, and a small number of true BlackFrost clues.

## Clean Rebuild

To rebuild, run the same command again:

```powershell
python .\scripts\build_lab_artifacts.py
```

The generated files in `dist\` are overwritten with fresh output from the current source. The build is deterministic as long as `scripts\build_lab_artifacts.py` is unchanged.

## Validate the Build

Confirm the expected files exist:

```powershell
Get-ChildItem .\dist
```

Confirm the hash:

```powershell
Get-FileHash .\dist\BlackFrost_Update.exe -Algorithm SHA256
Get-Content .\dist\SHA256SUMS.txt
```

Extract strings:

```powershell
python .\scripts\extract_strings.py .\dist\BlackFrost_Update.exe
```

You should see indicators such as:

- `BLACKFROST_CFG_B64=`
- `Global\BFROST-6E7A-PESTUDIO`
- `VirtualAllocEx`
- `WriteProcessMemory`
- `CreateRemoteThread`
- `WinHttpSendRequest`
- `BF_OVERLAY_V2`

Validate the final answer checker:

```powershell
python .\scripts\check_answer.py "pwndora{pe_studio_strings_unmask_blackfrost}"
```

Expected output:

```text
Correct flag.
```

## Player Package

For a player-facing release, provide:

- `dist\BlackFrost_Update.exe`
- `dist\README_FIRST.txt`
- `dist\network.log`
- `dist\memory_strings.txt`
- `docs\info.md`
- `docs\scenario.md`

Do not include these files in the player package unless you want to publish the solution:

- `docs\walkthrough.md`
- `docs\answers.md`
- `scripts\check_answer.py`
- `scripts\build_lab_artifacts.py`

## Instructor Package

For instructors or challenge maintainers, include everything:

- `README.md`
- `BUILD.md`
- `docs\`
- `scripts\`
- `dist\`

The walkthrough and answers contain the final flag and full solution path.

## Customizing the Lab

Most challenge content is controlled from `scripts\build_lab_artifacts.py`.

Useful values to modify:

- `FLAG`
- `SAMPLE_NAME`
- `XOR_KEY`
- `family`
- `campaign`
- `mutex`
- `c2`
- `task_name`
- decoy strings
- suspicious API strings
- overlay clue

After changing any of these, rebuild:

```powershell
python .\scripts\build_lab_artifacts.py
```

Then update the solution docs if the intended answers changed.

## Safety Notes

The generated sample is for static analysis training only. It is intentionally inert and does not implement malware behavior. Still, distribute it with clear instructions that players should analyze it in a lab environment and should not execute suspicious binaries during malware-analysis exercises.
